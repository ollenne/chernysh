ХЭЛЛОУИН Кота Черныша

Это уютная детективная мини-игра, разработанная в жанре визуальной новеллы. Помогите Чернышу разобраться с пугающими событиями, которые начались в хэллоуинский вечер...

Исследуйте улики, сопоставляйте факты и преследуйте загадочного виновника хаоса.

В данный момент доступны версии только для PC и Mac:

Скачать для Windows

Windows 10 и 11. Если Windows покажет «Windows защитила ваш компьютер» — нажмите «Подробнее» → «Выполнить в любом случае».

Скачать для Mac

macOS. При первом запуске: правый клик по игре → «Открыть»; если не открывается — «Системные настройки» → «Конфиденциальность и безопасность» → «Всё равно открыть».
